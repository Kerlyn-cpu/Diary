# Python Command-Line Apps

## Description
A collection of interactive command-line applications built in Python. This repository includes a digital diary and a task manager.

## Projects Included
### 1. Digital Diary (`Diary.py`)
Allows users to write, append, and read diary entries stored in a local text file.
- **Skills demonstrated:** File I/O operations (`'w'`, `'a'`, `'r'` modes), `while` loops, user input handling.

### 2. To-Do List Manager (`to_do_list.py`)
An interactive task manager that saves events, dates, and times to a text file. Includes error handling to prevent crashes on invalid input.
- **Skills demonstrated:** `try/except` blocks, `while` loops, string formatting, file appending.

## Technologies Used
- Python 3

## How to Run
1. Run the diary:
   `python3 Diary.py`
2. Run the to-do list:
   `python3 to_do_list.py`
